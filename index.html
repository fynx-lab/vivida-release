Vivida

A local image browser. The grid appears as soon as the folder is listed. Thumbnails fill in afterward, so a large folder does not wait on every decode.

Download Windows installer 0.0.1 · Windows 64-bit · Install for your account, no admin required · Report an issue
The grid comes first

Files are listed immediately. Only the thumbnails on screen are decoded, and off-screen ones make room.

Preview matches the window

The first view is sized to the screen. Original pixels are decoded when you zoom to 100%, not the moment the picture opens.

Common formats included

JPEG, PNG, WebP, TIFF, GIF, AVIF, HEIC, plus BMP and TGA. Animated GIFs start playing while later frames are still decoding.

Pin folders from the sidebar, sort by name, date, or size, and rename files. Deleted files go to the Recycle Bin.
